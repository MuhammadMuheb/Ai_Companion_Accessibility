    Features

    Everything a personal assistant should do — without the cloud.

    MD lives in the system tray, stays silent until you call it, and works by voice from start to finish: settings, goals and memories included.

    Wake word, fully hands-free

    A light speech model listens for “Hey MD” all day using a fraction of the CPU. The accurate model only starts once it hears its name. Keep talking — MD follows up until you say “bye” or “bas”.

    • Voice print: only your enrolled voices can wake it
    • Push-to-talk hotkey as a backup
    • Adjustable sensitivity, custom wake names
    “Hey MD” · confidence 0.91

    Memory that updates itself

    Tell MD you moved or changed jobs — the old fact is replaced, not duplicated, and the change is kept in a history.

    − User is travelling to Dubai
    + User is travelling to London

    Controls your PC

    Open apps and the right browser account, search the web, change volume, run multi-step routines.

    open gmail on work accountwork modevolume down

    Reads notifications aloud

    WhatsApp, Outlook, Teams and any Windows toast — plus unread counts in browser tabs, even when a site’s own alerts are off.

    WhatsApp · Mama Ji: “Khana kha liya?”
    Outlook · Invoice for September

    Reminders & prayer times

    Morning check-ins, focus sessions and namaz alerts calculated for your city — Karachi, MWL, Umm al-Qura and more, Hanafi or Shafi.

    Fajr 4:52Dhuhr 12:14Asr 4:39Maghrib 6:21

    Screen reading & Roman Urdu translation

    Built for accessibility. Press Ctrl Alt T to translate the selected text — or the text under your mouse — into Roman Urdu. Windows’ own OCR reads anything on screen, and every answer is short enough to be spoken.

    ENYour appointment is tomorrow at 10 am.
    URAap ki appointment kal subah 10 baje hai.

    WhatsApp by voice

    “Send Mama Ji: I’ll be late.” MD checks the open chat’s name on screen before pressing send.

    Private by design

    Local model via Ollama, memory in a SQLite file on your disk. While Windows is locked, only safe commands run.

    How it works

    From your voice to done — in four local steps.

    Every stage runs on your machine. Nothing is uploaded unless you turn on the optional expert mode with your own API key.

    1. 01

      Wake

      Whisper tiny scans the first 3 seconds of each sentence it hears for your wake name.

      ≈ 1.5 s CPU per 5 s of audio
    2. 02

      Understand

      Whisper base transcribes the command in English, Urdu or Roman Urdu with your names as hints.

      faster-whisper · int8
    3. 03

      Decide

      Fast rules match known commands instantly; anything else is classified or answered by the local model.

      qwen2.5 1.5B · Ollama
    4. 04

      Act & speak

      MD runs the action and speaks the reply sentence by sentence, so you hear the first words right away.

      Windows SAPI voices

    Architecture at a glance

    A single tray process owns the microphone, scheduler and services. The window is an accessible WebView2 page that talks to the core in-process — no open ports, and fully usable with a screen reader.

    • Prompt layout tuned so Ollama reuses its cache between replies
    • Chat model kept warm; history trimmed in chunks
    • Single-instance guard — launching again just opens the window

      FAQ
      
          
      Questions, answered.
      
        
      
        
      
          
      Does MD send my voice or data to the internet?
            
      No. Speech recognition, the chat model, memory and screen reading all run on your computer. Web searches go
              out only when you ask for one, and the optional expert mode uses Claude only with your own API key and a weekly budget you set.
      
          
      Do I need a graphics card?
            
      No. MD is tuned for CPU-only laptops. A GPU or a newer CPU simply makes replies faster.
      
          
      Which languages does it understand?
            
      English, Urdu, Hindi and Roman Urdu. Replies come back in the language you speak, and English text can be translated into Roman Urdu with one hotkey.
      
          
      Can it be used with a screen reader?
            
      Yes. MD’s window is a standard web page inside WebView2, so screen readers can read every control. Most people never open it: everything works by voice.
      
          
      What happens when my PC is locked?
            
      Only safe commands run — like the time, reminders or reading notifications. Anything that opens apps or sends messages waits until you unlock.
      
          
      Windows says “Windows protected your PC”. Is it safe?
            
      MD isn’t code-signed yet, so SmartScreen warns about every new download. Click More info → Run anyway. To be sure the file is genuine, compare its SHA-256 (shown under the download button) with Get-FileHash MD-Setup-1.0.0.exe in PowerShell.
      
          
      How do I uninstall MD?
            
      Windows Settings → Apps → MD → Uninstall, or “Uninstall MD” in the Start menu. The uninstaller asks whether to keep your memories and settings.
      
          
      How do I stop it from starting with Windows?
            
      Switch off “Start with Windows” on MD’s settings page. You can also quit it from the tray icon at any time.
