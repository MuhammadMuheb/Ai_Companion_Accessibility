My Commands

Make your own commands. When you say the phrase, the companion does the steps in order. Use 🎤 to dictate instead of typing.

Steps you can use
  • open notepad, open gmail, open youtube.com
  • type Assalam-o-Alaikum, press enter, press ctrl+s
  • say: Good morning! Let's start the day. — speaks a message
  • wait 2 — pause 2 seconds
  • start focus for 50 minutes, remind me in 30 minutes to stretch
  • what time is it, namaz ka time, what are my goals, volume down

Accounts

When you say “open YouTube”, I ask which account to use. Each browser profile is one account. Tick the profiles that belong to each site and give them the names you will say — e.g. YouTube: “NexTube”, “Ruhani Nasheeds”. If nothing is ticked for a site, I offer all profiles.

WhatsApp contacts

Tell me how you say a name and how it is saved in WhatsApp. A phone number (with country code, e.g. +92…) opens the exact chat; without it I search WhatsApp for the saved name. I always read the message back and ask before sending.

      Background

      MD lives in the tray (near the clock). Closing this window keeps it running; use Quit in the tray menu to stop it. Ctrl+Alt+N opens this window from anywhere. While Windows is locked MD still listens and can answer, remind and read notifications, but won't control the computer until you unlock it.
